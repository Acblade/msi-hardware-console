# MSI Hardware Console 0.1.7

## English

This small UI refinement keeps Thermal guard concise on both compact and wide windows.

- Hover help now contains only the information that is not already visible on the three cards
- All three temperature sliders share a maximum width of 460 px instead of stretching indefinitely
- Protection thresholds, timing, safety constraints, and hardware compatibility are unchanged

The executable is unsigned; verify the attached SHA-256 file before running it.

## 中文

这次小幅界面调整让“高温保护”在普通窗口和宽窗口下都更加简洁。

- 问号悬停提示只保留三张卡片外没有展示的信息
- 三条温度滑条统一限制为最大 460 像素，不再随宽窗口无限拉长
- 保护温度、触发时间、安全约束和硬件兼容范围均未改变

当前可执行文件没有代码签名，运行前请核对随 Release 提供的 SHA-256。
