# MSI Hardware Console 0.1.0

## English

First public preview of an unofficial lightweight MSI laptop dashboard and fan controller.

Highlights:

- English-default UI with instant Simplified Chinese switching
- CPU, discrete GPU, integrated GPU, storage, temperature, and fan RPM dashboard
- In-window 60-second performance charts and fan-curve overlays
- Automatic, Silent, Balanced, Boost, Fixed, Custom, and Full Blast controls
- Verified fan writes on MSI Cyborg 15 A13VE with MSI WMI 2.8
- Monitoring-only safety lock on all unverified hardware
- Portable Windows x64 archive; no MSI Center dependency

Important: the executable is unsigned. Windows may display an unknown-publisher warning. Check the attached SHA-256 file before running it.

## 中文

这是非官方轻量 MSI 笔记本硬件面板与风扇控制工具的首个公开预览版。

主要内容：

- 默认英文，可即时切换简体中文
- CPU、独显、核显、硬盘、温度与风扇 RPM 面板
- 当前窗口内的 60 秒性能图表和风扇曲线浮层
- 自动、静音、均衡、强冷、固定、自定义和狂暴散热
- 已在 MSI Cyborg 15 A13VE、MSI WMI 2.8 上验证风扇写入
- 所有未验证硬件默认锁定写入，仅提供监控
- Windows x64 便携压缩包，不依赖 MSI Center

注意：当前可执行文件没有代码签名，Windows 可能显示未知发布者警告。运行前请核对随 Release 提供的 SHA-256 文件。
